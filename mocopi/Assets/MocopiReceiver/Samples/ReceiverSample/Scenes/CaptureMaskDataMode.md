# CaptureMaskDataMode

`CaptureMaskDataMode.unity` を開いて Play すると、mocopi のポーズから壁の穴を撮影・確認・保存できます。ReceiverSample と同じアバターと UDP 12351 の受信設定を使用します。

1. mocopi を使う場合は、この PC の IP アドレス・UDP 12351 に送信します。**未接続でも撮影できます**。その場合は表示中のアバターのポーズ（初期ポーズや最後に受信したポーズなど）を撮影します。
2. 正面に無地の壁が配置されます。必要なら **P** または画面の配置ボタンで、現在のプレイヤー位置とカメラの水平方向を基準に配置し直します。配置し直すと未保存のプレビューは破棄されます。
3. **Space** または「撮影」を押し、3 秒のカウントダウン中にポーズを取ります。カウントダウン終了時のポーズ型が、無地の壁の右隣に表示されます。
4. 撮影直後は余白 **0cm** です。「輪郭から外側への余白」スライダーで **0〜30cm** を調整します。幅を変えても現在のアバターを撮り直すことはありません。手直ししていないマスは0に戻すと元の輪郭に戻ります。
5. 画面右側の「型の手直し」グリッド、または3Dの撮影結果をクリックして最終形を整えます。**Cube追加** は穴を狭め、**Cube削除** は穴を広げます。左クリックは選択中のツール、右クリックは削除です。ドラッグで連続編集できます。紺色の穴にもCubeを追加できます。
6. **Ctrl+Z / 元に戻す**、**Ctrl+Y / やり直す** で手直しを取り消し・復元できます（最大50操作、ドラッグは1操作）。「手直しを解除」で現在のスライダー幅の型に戻ります。この解除も取り消せます。手直ししたマスはスライダーを動かしても保持されます。
7. よければ **S** または「保存」。画面の最終形がそのままJSONになります。別のポーズを追加する場合は **R** または「撮り直す」を押してから、もう一度撮影します。Space で直接再撮影することもできます。再撮影すると手直しと履歴は初期化されます。保存後に幅やマスを変更すると、その形を別ファイルとして追加保存できます。

撮影結果は固定されます。その後の体の動きや切断で変わりません。未接続でも撮影・余白調整・保存ができます。カウントダウン中に切断しても中止せず、終了時点のアバターのポーズを撮影します。有効なHumanoidアバターと撮影用の壁は必要です。

## 保存とゲームでの利用

- 保存先は `Application.persistentDataPath`。完全なパスを画面と Console に表示します。
- ファイル名は `mocopi_pose_日時_固有ID.json`。既存ファイルを上書きせず、変更のないプレビューの二重保存を防ぎます。画面に同じグリッドの有効な保存データ数を表示します。20個を目安にポーズを追加してください。
- 既存の `WallMaskData` の JSON 形式（上から順に `rows`、`1` が壁、`0` が穴）で保存します。
- 壁が1マスも残っていない形・穴が1マスもない形は保存できません。Cubeを追加・削除してから保存してください。
- `WallMaskData` Inspector の Saved Mask Data から確認・読み込みできます。実行時には `LoadSavedMaskData(path)` を使用できます。
- 現在の撮影シーンとGameModeは 30 行 × 60 列、1 セル 0.1m（幅 6m × 高さ 3m）です。使用するゲーム用 WallBuilder とグリッド数・セルサイズを合わせてください。
- GameMode の1P/2P用 WallManager prefab は **Use Saved Masks** が有効です。ゲーム開始時に保存先のJSONを読み込み、**Wall Count（既定10）** 個を抽選します。20個あれば重複なしで10個が出現し、再プレイ時には再抽選します。各レーンは個別に抽選します。
- データが10個未満なら全種類を一度ずつ出してから再抽選し、10問を出題します。有効なデータが0個ならConsoleに理由を出し、従来の出題方式を使います。不正なJSON、穴だけ／壁だけのデータ、グリッド数が異なるデータは出題しません。
- **Saved Mask Directory** が空なら `StreamingAssets/PoseMasks` の同梱60枚（右20・中央20・左20）と撮影の保存先を合わせて使用します。同じ形のローカルコピーは重複しません。同梱データは別PC・配布ビルドでも利用できます。この欄にフォルダを指定した場合はそのフォルダだけを使用します。**Use Saved Masks** をオフにすると従来の出題方式に戻ります。
- `WallMaskData` Inspector の **Save Current Mask Data** も保存ごとに新しいファイルを追加します。

## 調整

シーン内の `CaptureMaskDataMode` Inspector で壁の距離・床の高さ・セル数・セルサイズ・Capture Samples Per Cell・キー・撮影待ち時間を調整できます。床の高さはワールド座標の Y です。壁の姿勢はカメラの水平方向に合わせ、床に対して垂直に保ちます。

穴は撮影時点のアバター配下の有効な SkinnedMeshRenderer を BakeMesh し、壁へ正投影したメッシュの輪郭です。MeshRenderer も含みます（こちらはメッシュの Read/Write が必要）。三角形の形を使うため、マテリアルの透明・アルファ抜きは反映しません。実際の人間の写真の輪郭ではありません。

既定では1セルを縦横4分割し、**1.25cm** 間隔で輪郭を取得します。その原形を保持し、円形の距離で余白を広げてから **5cm** の壁セルに変換します。元の骨格カプセル近似と半径の切り上げ・自動10cm拡張は撮影モードでは使いません。最終的な壁の段差は5cm単位で残ります。これを細かくする場合はゲーム側 WallBuilder も同じセルサイズとセル数にして再生成してください。

保存するJSONは調整後の最終マスクです。原形を再編集するための高精度データは保存せず、その撮影のプレビューを保持している間だけ幅を戻せます。過去に太く保存したJSONは新方式で撮影し直してください。

このシーンは Editor から単独で起動できます。ビルドに含める場合は Build Profiles の Scene List に追加してください。

モデルや親オブジェクトのスケールは撮影にも一度だけ反映します。`BakeMesh(mesh, true)` でスケール補正した頂点を Transform の座標変換で壁へ投影します。以前の二重スケールで保存したJSONには補正が入らないため、再撮影してください。

## Maoモデルの揺れ

Mao用Prefabには `MaoSecondaryMotion` が付いています。Play中、横髪・ツインテール・エプロン・しっぽの29本と前髪の毛先1本に、体の動きに遅れて追従する揺れを加えます。Humanoidの体のボーンやモデルのスケールは変更しません。前髪は `fronthair1` とHumanoidのJawに割り当てられた `fronthair2` を固定し、先端の `fronthair3` だけを動かします。リボンなど専用の揺れボーンがないパーツは、元のスキニング先に追従します。

- Inspectorの **Motion Amount** は揺れ角の上限倍率です。0にすると元の形に戻ります。コンポーネントを無効にしても揺れを停止できます。
- **Hair / Fringe Tips / Clothing / Tail** の **Frequency** を上げると素早く戻り、**Damping** を上げると振動が収まりやすくなります。**Max Angle** は最大の傾きです。
- **Fringe Tips** は毛先専用です。既定の角度上限は左右3度、戻りはやや速めで減衰を強くしています。顔に沿う平面内だけで揺れ、前後への変位を加えません。頭の向きが変わっても左右の揺れ方向が追従します。風の影響も他の髪の4分の1です。
- **Air Movement** はごく弱い風です。0にすると体の動きだけで揺れます。
- **Body Collision** は頭・胴・太ももの簡易形状でめり込みを抑えます。服や髪の表面全体を計算するClothではありません。
- 大きな位置・角度・スケールの変化や長いフレーム停止では慣性をリセットし、跳ねを抑えます。撮影は揺れの計算後に行うため、その時点の形を固定して保存します。

## 自動検証

Unity を閉じた状態で以下を実行できます（Unity.exe のパスはインストール環境に合わせてください）。検証では実機の代わりに受信状態を登録し、実機との通信は行いません。

```powershell
& 'C:\Program Files\Unity\Hub\Editor\6000.4.1f1\Editor\Unity.exe' -batchmode -nographics -projectPath . -executeMethod CaptureMaskDataValidation.RunAll -quit -logFile Logs/capture-mask-validation.log
```

成功時はログに `CAPTURE_MASK_VALIDATION_PASSED`、`PRECISE_CAPTURE_LIBRARY_VALIDATION_PASSED`、`CAPTURE_CELL_EDITOR_VALIDATION_PASSED` が出ます。シーン参照、上下方向、メッシュ輪郭、余白を戻した際の復元、円形拡張、Cube編集・Undo/Redo・余白との併用、JSON保存・読込、不正データ除外、20個から10個の重複なし抽選、実際の生成壁と保存形の一致、再プレイ、複数保存、接続判定を検証します。

プロジェクトのコピーで `-executeMethod CaptureMaskEditorPlayValidation.Run`（`-nographics` と `-quit` は付けない）を実行すると、Play中のクリック・連続編集・取り消し・再撮影を検証し、Unityを終了します。通常起動では `Logs/CaptureMaskEditor/edited.png` に画面も保存します。`-batchmode` を付けた場合は画面保存を省略します。実機mocopiの通信は別途確認してください。
